## October 11, 2026 — post/page studio editor (this session)

Times below are Eastern Daylight Time (UTC−4), from the editor session.

### ~3:46–3:58 PM — Preview / Save draft / Publish looked disabled

- Those buttons were grayed out when **Post title** was empty. The heading inside the article is not the post title.
- Preview, Save Draft, and Publish now stay clickable. If the title is missing, they jump to the **Post title** field, ring it, and explain that the list name is required.

### ~3:58–4:08 PM — Box around the title in editor and draft preview

- Public preview and unselected canvas headings were rendering the **left-panel heading editor** (bordered box, editor chrome).
- Headings on the canvas and in preview now render as plain titles. The inspector heading field no longer uses that outline.

### ~4:08–4:22 PM — Section chrome too large; extra containers; Flexbox/Grid always open

- Section **Edit / Copy / Container / Up / Down / Delete** controls are **icons only**, hidden until hover or section select (Elementor-style).
- The **+** between sections is hidden until you hover the gap, and does not receive clicks while hidden.
- Unused empty Flexbox/Grid placeholders are not stacked; leftover empty containers are dropped on load.
- Flexbox/Grid is not meant to sit in the left panel while you edit text. It belongs with **container** editing.

### ~4:22–4:32 PM — Layout picker still in the inspector; empty container still appearing

- Flexbox/Grid in the side panel is tied to **selecting the container**, not to editing a text widget.
- Extra unused empty sections continued to be stripped rather than reused as a fake new container.

### ~4:32–9:19 PM — Click the yellow box vs click outside it

- **Yellow box** = widget (text/heading). Click the words to edit the widget. Left panel: text editor.
- **White space / padding around the widget** = the **section**. Click there to highlight the whole section. Left panel: container layout (column width, Flexbox/Grid).
- Loose top-level paragraphs/headings are wrapped into real one-column sections so that click target exists.

### ~9:19–9:28 PM — Old stacked Edit/Copy bars came back; white space still not clickable

- Posts without `section`/`skin` metadata fell back to the old **BlogDraggableBlock** list (full labeled bars, “Add block”).
- Page/post editors now stay on the **brand canvas**. The footer **Add** button always adds a section.
- Widget vs section click uses **content** (paragraphs, headings, the live editor), not the entire widget wrapper.

### ~9:28–9:32 PM — Blank green studio page

- A `useEffect` cleaned unused sections with `Array.filter()`, which always returns a **new array**, so the store updated forever and React never painted.
- Cleanup now keeps the same array reference when nothing was removed, and skips the store write when block identity is unchanged.
